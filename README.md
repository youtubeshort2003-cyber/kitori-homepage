# 紀とり｜KITORI — 公式ホームページ

和歌山県御坊市の炭火焼き鳥「紀とり」のホームページです。
依存パッケージ不要の静的サイト（HTML / CSS / Vanilla JavaScript）で構成しています。

## 特徴

- **和モダンの上質なデザイン** — 墨黒と熾火の金を基調に、明朝体で構成
- **演出** — スクロール出現、炭火の熾（おき）が舞う粒子アニメーション、パララックス
- **完全レスポンシブ** — スマートフォン・タブレット・PC に対応
- **アクセシビリティ配慮** — `prefers-reduced-motion` 対応、セマンティックなマークアップ
- **高速・軽量** — フレームワーク不使用、画像は最小限（外部フォントのみ読込）

## 構成

```
site/
├─ index.html              … ページ本体（1ページ完結）
├─ assets/
│  ├─ css/style.css        … スタイル一式
│  ├─ js/main.js           … 演出・ナビ・アニメーション
│  └─ img/favicon.svg      … ファビコン
└─ README.md
```

## ローカルでの確認方法

```bash
cd site
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 公開（デプロイ）

`site/` ディレクトリをそのまま下記いずれかにアップロードするだけで公開できます。

- GitHub Pages（`site/` を公開ディレクトリに指定）
- Netlify / Vercel（publish directory を `site` に設定）
- レンタルサーバー（FTP で `site/` の中身をアップロード）

## 公開前に差し替えをおすすめする項目

| 項目 | 場所 | 状態 |
|------|------|------|
| メニュー・価格 | `index.html` お品書き | **参考値**。実際のメニュー・価格に要差し替え |
| コース内容・価格 | `index.html` お品書き | **参考値**。実施していなければ削除可 |
| 写真 | （現在は CSS の意匠で代替） | 実店舗・料理写真の追加を推奨 |
| コンセプト文・店主の言葉 | `index.html` 想い | 雰囲気重視の文章。実際のこだわりに合わせて調整可 |

### 写真を追加するとさらに本格的になります

`assets/img/` に料理・店内・外観の写真を置き、ヒーローや空間セクションの
背景に設定すると、より訴求力のあるサイトになります。
（撮影：炭火と料理を暗めの背景で寄りで撮ると、本サイトの世界観に合います）
